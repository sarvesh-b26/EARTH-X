Scale and uncertainty disclosure

LOLA polar site products are 5 m/pixel and include separate count, slope and uncertainty layers. The displayed 128×128 view is a reduced preview of a 640 m square source window. MOLA 128 ppd is roughly 463 m per latitude cell; longitude spacing varies with latitude. These native-resolution previews are not directly comparable to the Earth 90 m source or to each other without a common-support workflow. No similarity percentage is generated here.

3 · Geological context resources

Geology is not inferred from terrain shape alone. Consult mapped lithology and mission-specific geochemical observations before making geological claims.

  • USGS Mineral Resources / geology data
  • USGS Astrogeology Science Center
  • NASA Planetary Data System
  • NASA PDS Geosciences Node – Mars data

These are reference pathways; v1.5 does not claim automated lithology extraction or geochemical integration.

Common-resolution comparison — current status

EARTH-X records the native pixel spacing and uses it in terrain calculations. The current point-sampled Earth elevation grid is not yet a true area-aggregated, co-registered common-support raster. Therefore, cross-body scores must remain exploratory. v1.5 exposes this limitation rather than disguising resampling as measured equivalence.
